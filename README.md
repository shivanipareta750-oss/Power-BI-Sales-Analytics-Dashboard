# Executive Sales Analytics Dashboard | Power BI

## Project Overview
Developed an interactive Power BI dashboard to analyze sales performance, revenue, gross profit, profit margins, product categories, sales channels, and geographical performance.

## Tools & Technologies
- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Microsoft Excel
- Data Visualization
- KPI Reporting

## Dataset Overview
- Source: Excel Sales Dataset
- Total Records: 2,707
- Total Columns: 16
- Key Fields: Order Date, Region, Country, Sales Channel, Product Category, Units Sold, Revenue, Gross Profit, and Gross Margin

## Key Performance Indicators
- Total Revenue
- Gross Profit
- Gross Margin
- Units Sold
- Country-wise Sales Performance
- Product Category Performance
- Sales Channel Performance

## Dashboard Features
- Interactive sales performance visualizations
- Revenue and profitability analysis
- Country-wise and regional sales comparison
- Product category analysis
- Sales channel performance analysis
- Business performance reporting

## Business Objective
To transform sales data into actionable business insights and support data-driven decision-making through interactive dashboards and KPI analysis.

## Project Files
- `Executive_Sales_Dashboard.pbix` — Power BI dashboard file
- `Sales_Data.xlsx` — Excel source dataset (to be uploaded)

## How to Use
1. Download the `.pbix` file.
2. Open it using Power BI Desktop.
3. Explore the dashboard to analyze sales performance and profitability.
